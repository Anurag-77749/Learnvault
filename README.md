# LearnVault — Personal Learning & FDE Tracker
> **Your Knowledge. Your Progress. Your Future.**

A high-performance private learning hub designed to eliminate distractions, master Data Structures & Algorithms, practice daily communication, and stay accountable on your 4-year journey towards becoming a Forward Deployed Engineer.

---

## 🚀 Key Features

- **Today's Mission & To-Do List**: Quick task management with rollover and note attachments.
- **Dynamic Milestone Tracker**: Daily progression counter (Day 2 of 1,460).
- **Wasted Days Accountability**: Multi-select distraction logging with permanent audit history.
- **Chrono Focus Timer**: Pomodoro intervals, unbounded stopwatch, and distraction counters.
- **Parallel Track Planner**: Multi-lane schedule with quick catch-up shifts (+7d, +14d).
- **Curriculum Tracker**: Deep coverage across CS Basics, DSA, Git, Linux, Frontend, Backend, Data, and AI Engineering.

---

## 🛠️ Stack

- **Framework**: React 18 + Vite + TypeScript
- **Styling**: Tailwind CSS (Royal Maroon & Metallic Gold)
- **Database**: Dexie.js (Client-side IndexedDB for 100% private offline persistence)
- **Icons & Motion**: Lucide React + Framer Motion
